# 参与改进

欢迎提交可复现的问题、说明修正和代码改进。

## 报告问题

请提供程序版本、Windows/微信版本、屏幕缩放、窗口大小、复现步骤，以及经过脱敏的错误类型和时间点。说明是查询失败、点击未生效、字段校验未通过还是保存失败。

请使用虚构数据复现。不要上传客户表格、真实运单号、姓名、电话、地址、截图中的个人信息、登录状态或原始运行日志。日志可能包含路径、单号片段和文件名；遮盖截图中的一小部分不一定足够。

## 修改代码

1. Fork 仓库并新建分支。
2. 在 Windows 上执行 `build.ps1` 和 `test.ps1`。
3. 针对涉及的失败/恢复场景验证。控件模拟测试不能替代对应微信版本的实机测试。
4. 在 Pull Request 中说明触发条件、修改后的行为、验证范围和限制。

保留运单号精确匹配、原表内容校验、外部修改检测和停止响应。不要用猜测的客户信息通过校验，也不要让验证码或访问限制被自动重试绕过。

此项目按 MIT 许可证分发。新增第三方代码时请保留其所需声明，并说明来源和许可证。
