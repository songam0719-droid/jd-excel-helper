# 使用说明（桌面工具 1.4）

独立 Windows 小工具，使用微信现有控件查询并写回本地表格。不调用 AI 模型，不消耗 WorkBuddy 等平台积分。

## 开始使用

1. 完整解压后双击“京东查单工具.exe”。Windows 10/11 需系统已有 .NET Framework 4.8/4.8.1，不用安装 Python。
2. 登录有查询权限的微信，打开京东快递小程序的“查快递”页，只保留一个京东窗口。
3. 关闭要处理的 Excel/WPS 文件，选择原 .xlsx 和工作表（默认 Sheet1）。
4. 第 1 行表头；F 列运单号，B/C/D 列姓名、电话、地址。每单保存，启动前自动备份。
5. 换电脑先试“本次数量=3”，核对后设为 0（全部）。数量统计实际尝试的单，已完整和默认跳过的不可读单不占数量。
6. 运行时保持电脑解锁、小程序可见，暂时不要操作鼠标。不同电脑各使用自己的表格。

## 网络慢时的点击确认

- 控件显示不代表点击生效。点击卡片、电子存根入口或小眼睛后持续检查页面变化。
- 小眼睛点击后，号码仍带星号才重新定位并重试；重点击间隔至少约 1.8 秒。号码显示完整即停止点击，每次点击前再次核对。
- 小眼睛步骤最多等待约 15 秒、最多点击 6 次；超时交给当前单的额外重试，避免无限卡住。
- 页面离开原界面后，停止重复点击旧入口，等待新页面数据加载。
- 明确已取消且没有电子存根、或暂无运单信息，直接标记不可读。取消但仍有电子存根的单继续正常读取。
- 详情页已确认属于当前运单后，约 6 秒还没有电子存根入口，则标记并返回。其他页面加载使用各自的等待上限。
- 时限是程序循环检查上限，系统控件调用和暂停可能增加实际经过时间。

## 每单额外重试

- 默认 1：首次查询失败后，最多再完整查询 1 次。设置 3 则每单最多完整查询 4 次。
- 0～5 是当前单的额外次数，不是整批允许失败的单数。没有失败累计达到 5 单就停机的规则。
- 点击未生效的局部恢复与整单重试分开计算；先在当前步骤恢复，仍失败再查询整单。
- 取消、暂无信息等明确无结果的单，不消耗全部重试次数。网络超时、控件临时刷新等错误才尝试恢复。

## 失败标记和断点续跑

- 最终失败的运单在 F 列显示浅红底、深红字；现有内容右侧新增“京东查单状态”列，记录“不可读｜运单号｜原因”。原运单号不改值。
- 标记存在 .xlsx 内，复制到另一台电脑仍有效；即使 JSON 丢失也能跳过。程序识别带运单号的状态文字，不会把原来手工涂红的单误当成不可读。
- “开始 / 断点续跑”默认跳过姓名、11 位手机号和地址都完整的行，也跳过已标记不可读的行，继续其他未完成行；中间空缺也会补。
- 主动复查失败单：勾选“重查不可读单”再开始。它允许这些单重新加入任务，同时仍处理其他未完成单，不会重查已完整行。
- 复查成功后清除不可读状态和程序的红色提示；仍失败则更新原因并保留。
- 修改 F 列号码后，旧状态不会套到新号码。也可停止工具后清空某行的“京东查单状态”，解除该行标记。
- 不要删除或改名状态列，除非有意解除全部标记。排序、移动整行时请包含该列。
- 旧版 JSON 中的失败记录尚未在表内标记；升级后会实际查询一次，仍失败才写入新标记。

## 暂停、停止和保存

- F8 暂停/继续，Ctrl+Alt+F9 停止，单独 F9 不停止。也可使用窗口按钮。停止来源记录在日志中。
- 关闭运行中的窗口会先请求停止，保存结束后再关闭。
- 文件被 Excel/WPS 占用、外部修改、无写权限，或小程序要求验证码、限制访问、登录失效、窗口缺失/被遮挡等全局问题仍会停止，排除后再续跑。
- 页面运单号必须完全一致；姓名和电话与原表前后缀匹配，已有完整地址不同不覆盖。号码隐藏或结构不明确不写入。
- 控件标签和相对位置有容错，姓名、电话、地址和运单号不进行相似度猜测。

## 文件位置与清理

- 结果和不可读标记：所选原 .xlsx。备份：原文件旁“京东查单备份”目录。
- 续跑记录：原文件名后加“.京东查单记录.json”，保存完成状态、待写入结果和错误。
- 运行锁：原文件名后加“.京东查单运行锁”，防止同时写入；锁文件存在不等于正在运行。
- 只有所选工作表的京东运单全部填完整、正常结束，才自动删除 JSON 和运行锁。停止、还有未完成或不可读单时保留。原表及备份始终保留。
- 日志：当前用户 LocalAppData\JdExcelHelper\Logs，点“查看日志”打开；整表完成后日志仍保留。

## 七台电脑使用

- 每台完整解压、登录自己的微信、选择自己的表格。没有共享任务队列，不会自动分配七台任务。
- 兼容性依赖微信/小程序版本和控件结构。此前验证过本机多种窗口尺寸及模拟 100%～200% 缩放，不等于七台不同配置均已实测。
- 不同网络、页面响应、机器性能下速度会变化，换机先试 3 单。

## 交付内容

- 京东查单工具.exe、使用说明.txt、测试记录.txt。
- 源码位于 GitHub 仓库 src/；根目录提供 build.ps1 和 test.ps1。
- build.ps1 使用 Windows 自带 C# 编译器，不需要联网下载依赖。

本工具只查询并回填本地表格，不发送消息、不联系客户、不下单、不支付。
